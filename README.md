Computer vision intern at **CombatIQ**, building models for sports analytics. I study Computer Science (UNIMA) and Business Administration (UFAL) in Maceió, Brazil.

I like taking a model all the way: gathering and labeling the data, training it, testing it honestly and making it fast enough to be useful in the real world.

### What I work on

- Video models that make decisions in real time
- Datasets, labeling tools and evaluation you can trust
- Small, efficient models that run well on ordinary hardware
